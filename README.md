# catfiles

Concatenate source files with language-aware fences.

```
python catfiles.py src --fence
```

## layout

- `tests/test_catfiles.py` - tests for the module next to it

## how to run

Runs on 3.11 and newer.

```
git clone https://github.com/CodingWithFardin/catfiles.git
cd catfiles
```

Tests: `tests/test_catfiles.py`. A change that breaks one is usually the wrong change.
